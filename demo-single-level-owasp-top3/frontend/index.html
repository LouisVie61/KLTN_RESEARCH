OWASP Top 3 — Single Reward Pool

Demo local: kết nối MetaMask, thực hiện transaction thật trên Hardhat Local, rồi quan sát invariant bị phá ở vulnerable pool và được khôi phục ở defended pool.

Chuẩn bị: chạy npm run node, npm run deploy:local, rồi mở thư mục frontend bằng HTTP server.

SC01 · VULNERABLE

Unauthorized access

Ai cũng có thể đổi reward rate. Hãy kết nối bằng Alice/attacker rồi gọi nút này.

attacker→setRewardPerBlockUnauthorized→state đổi
SC01 · DEFENDED

Access denied

Function có onlyOwner. Kết nối bằng non-owner để thấy MetaMask gửi transaction nhưng contract revert.

non-owner→onlyOwner→revert
SC01 · AUTHORITY

Owner configuration

Kết nối bằng owner để thay đổi cấu hình hợp lệ của defended pool.

SC02 · VULNERABLE

Retroactive rate

Ghi rate mới trước khi checkpoint. Chuỗi demo: deposit 100 → mine 10 → đổi rate 10 → mine 5 → claim.

SC02 · DEFENDED

Epoch checkpoint

Contract gọi _updatePool() trước khi lưu rate mới. Chạy cùng một chuỗi để so sánh.

Chưa chạy
SC02 · INVARIANT

Expected calculation

10 × 1+5 × 10=60 DRW

Vulnerable pool định giá cả epoch cũ bằng rate mới: 15 × 10 = 150 DRW (xấp xỉ, vì transaction tạo thêm block).

SC05 · VULNERABLE

100% fee accepted

Owner đặt 10,000 BPS. Alice approve và deposit 100 DST; toàn bộ token đi tới owner, Alice được credit 0.

SC05 · DEFENDED

Fee boundary

Fee lớn hơn 1,000 BPS bị từ chối. Với 1,000 BPS, deposit 100 DST chỉ credit 90 DST.
